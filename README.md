# EnergiaSentinela IA

Protótipo conceitual desenvolvido para o **Grand Prix SENAI 2026 — Eficiência Energética**, pela equipe da Agência SENAI Sonora (MS).

A solução demonstra como sensores de temperatura e corrente, combinados com inteligência artificial, podem:

- detectar aquecimentos e consumos anormais;
- estimar perdas em kWh e em reais;
- prever riscos de falha;
- priorizar intervenções de manutenção entre P100 e P1.

> Os dados apresentados no painel são simulados para demonstração do protótipo.
